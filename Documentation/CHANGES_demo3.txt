ThermoSet Connect - demo3  (= your demo2 + minimal fixes)
==========================================================
ONLY these 4 files changed. Copy just these into your working folder
(ThermoSet_Connectrishi\ThermoSet_Connect). Do NOT overwrite esp01.h -
it holds your WiFi name/password and ThingSpeak keys.

1. main.c
   - ALERT FIX: temperature is in VOLTS, set point is in degC, so the buzzer
     and cloud alert never triggered. Now temp_c = temperature*100 is used for
     the comparison and for every upload.
   - RTC: sec/min/hour/date/month/year/week had no value before being written
     into the RTC. They now get a default (12:00:00, 21/09/2026).
   - interrupt_flag is volatile + switch debounce (menu does not re-open).
   - WELCOME MESSAGE: new function welcome_msg(), called right after
     init_keypad(). "WELCOME TO THERMOSET CONNECT" scrolls right-to-left on
     line 1 (line 2 shows "IoT Temp Monitor"), then "THERMOSET / CONNECT" is
     held for 2 s. Speed: change WELCOME_SCROLL_MS (120 ms per step, ~5.5 s scroll).

2. esp01.c   (only the tail of esp01_readThingspeakField changed)
   - Remote set point read: the ESP reply ends with the word CLOSED
     (+IPD,2:40CLOSED), so the old "digits at the end" parser always failed.
     Now the value is read from after the ':' of +IPD,<len>:.
   - Nothing else in the ESP01 command sequence was touched.

3. esp01_call.c
   - update_data(): waits until 16 s after the previous upload (ThingSpeak free
     plan drops updates faster than 15 s - e.g. "set point" upload followed
     straight away by the alert upload).
   - sync_cloud_setpoint(): a set point typed on the keypad is no longer
     overwritten by the OLD value still on the cloud (last cloud value is kept
     in EEPROM address 0x78).
   - LCD text "SetPoint updated" (fits 16 characters).

4. uart.c
   - UART interrupt cannot write past the end of buff[300].

HOW TO CHECK THE ALERT
   Switch -> 2 (SP) -> enter a value BELOW the LCD temperature (e.g. 20 when it
   shows 27) -> # -> 4 (EXIT). Buzzer beeps 3x every loop; ThingSpeak field 2
   receives the temperature once. Enter a value above the temperature: buzzer stops.
